## 30-Second Example

```yaml
id: tc_login
title: User Login Test
prodURL: https://www.saucedemo.com
expectedResult: Inventory page is displayed after login.

steps:
  - navigate: /
  - act: Type '${username}' into the 'Username' field
  - act: Type '${secret.SAUCE_PASSWORD}' into the 'Password' field
  - act: Click on the 'Login' button
  - validate: Verify 'Products' page title is displayed
```

Run tests with one command:

```bash
zenitest run --dir zenitests
```
