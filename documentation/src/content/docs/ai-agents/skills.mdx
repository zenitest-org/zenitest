Install the ZeniTest skill into your AI coding assistant (**Cursor**, **Claude Code**, **Antigravity**, **Codex**, and 70+ agents) so it can automatically write, update, and run your tests.

---

## 1. Install the Skill

Run this command in the root folder of your project:

<Tabs>
  <TabItem label="npm">
    ```bash
    npx skills add zenitest-org/skills
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm dlx skills add zenitest-org/skills
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn dlx skills add zenitest-org/skills
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bunx skills add zenitest-org/skills
    ```
  </TabItem>
</Tabs>

Select your agent when prompted (or choose all), and the installer will place the skill directly in your project.

---

## 2. How to Use with your AI Assistant

Once installed, you can talk to your AI assistant normally or use `/zenitest`.

### Create New Tests
> *"Create a web test for our sign-up page at `/signup`"*  
> *"Write an iOS test for adding an item to the shopping cart"*  
> *"Write an Android test for the checkout workflow"*

### Update Tests After Code Changes
> *"We updated the login button to say 'Sign In'. Please update our test cases."*

### Run Tests and Fix Failures
> *"Run our web tests and fix any failing steps."*
