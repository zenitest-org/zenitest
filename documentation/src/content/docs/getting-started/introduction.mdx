**ZeniTest** lets you create automated tests for Web, iOS, and Android apps using simple plain English YAML files. 

Instead of writing complex code or maintaining fragile CSS selectors, you write what you want to do (like clicking a button or typing text), and ZeniTest's AI takes care of running and verifying it.

---

## Why ZeniTest?

- **Plain English Tests**: Write test steps in simple sentences anyone can understand.
- **One Tool for Web & Mobile**: Run tests on websites, iOS apps (`.ipa`), and Android apps (`.apk`).
- **No Fragile Selectors**: No need to inspect elements or copy XPath/CSS selectors.
- **AI Visual Checks**: Verify pages and screens visually, just like a human tester.
- **Safe Secrets**: Keep passwords and private keys out of your test files.
- **Fast CLI**: Run your tests directly from your terminal with a single command.

---

## How It Works in 3 Steps

1. **Write a Test**: Create a `.yaml` file with the actions you want to take (`navigate`, `act`, `validate`).
2. **Run the Command**: Run `zenitest run` in your terminal.
3. **See Results**: View live pass/fail results right in your terminal.
