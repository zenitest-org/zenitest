**ZeniTest** is an AI-powered automated testing tool. It lets you write end-to-end (E2E) tests for Web, Mobile iOS (`.ipa`), and Mobile Android (`.apk`) applications in simple YAML files using natural language instructions.

## Key Features

- **Cross-Platform E2E Testing**: Automated testing for Web, iOS, and Android applications.
- **No CSS/XPath Maintenance**: Describe taps, typing, or clicks in plain English.
- **AI Visual Verification**: Verify page and screen content visually without complex assertions.
- **Cloud & Local Device Execution**: Run mobile tests seamlessly on real cloud devices, simulators, or emulators.
- **Built-in Secret Security**: Use `${secret.MY_KEY}` to keep credentials safe.
- **Parallel & Multi-Platform Runs**: Execute test suites concurrently across platforms.

## How It Works

1. **Write YAML**: Define your test scenario in `.yaml` files organized by platform inside `zenitests/` (`web/`, `ios/`, `android/`).
2. **Run CLI**: Execute `zenitest run` in your terminal with your app binary or web settings.
3. **Get Results**: The Zeni AI executes your steps and reports real-time visual results and logs.
