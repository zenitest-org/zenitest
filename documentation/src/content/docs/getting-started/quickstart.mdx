Run your first automated test in under 2 minutes.

> **Before you start:** Make sure you have the necessary tools for your platform (browsers for Web, Android Studio for Android, Xcode for iOS). See [Requirements](/getting-started/requirements/) for the full checklist.

---

## 1. Install the CLI

Install the `zenitest` command line tool globally:

<Tabs>
  <TabItem label="npm">```bash npm install -g zenitest ```</TabItem>
  <TabItem label="pnpm">```bash pnpm add -g zenitest ```</TabItem>
  <TabItem label="yarn">```bash yarn global add zenitest ```</TabItem>
  <TabItem label="bun">```bash bun install -g zenitest ```</TabItem>
</Tabs>

---

## 2. Install AI Agent Skill

Install the ZeniTest skill into your AI coding assistant (Claude Code, Cursor, Antigravity, Codex, etc.) so it can write and maintain tests for you:

<Tabs>
  <TabItem label="npm">```bash npx skills add zenitest-org/skills ```</TabItem>
  <TabItem label="pnpm">
    ```bash pnpm dlx skills add zenitest-org/skills ```
  </TabItem>
  <TabItem label="yarn">
    ```bash yarn dlx skills add zenitest-org/skills ```
  </TabItem>
  <TabItem label="bun">```bash bunx skills add zenitest-org/skills ```</TabItem>
</Tabs>

---

## 3. Log in with your API Key

Link your account using your API key:

```bash
zenitest auth <your_api_key>
```

---

## 4. Generate Tests with AI

You can now use the `/zenitest` command in your AI coding assistant to automatically generate your test files:

```text
/zenitest Create a Web E2E test case for our login flow
```

Or for mobile apps:

```text
/zenitest Create an Mobile test for our checkout workflow
```

Your AI assistant will create the test `.yaml` file directly in your `zenitests/` directory.

### Example Generated Test (`zenitests/web/tc_login.yaml`)

```yaml
id: tc_login
title: Login Test
expectedResult: User is logged in and sees the product inventory.

steps:
  - navigate: /
  - act: Type 'standard_user' into 'Username'
  - act: Type 'secret_sauce' into 'Password'
  - act: Click 'Login'
  - validate: Verify 'Products' page title is displayed
```

---

## 5. Run the Tests

Execute your test suite from your terminal:

Run all tests:

```bash
zenitest run
```

Run only web tests:

```bash
zenitest run --platform web
```

Run mobile tests:

```bash
zenitest run --platform android --bundle ./build/app-debug.apk
```
