Run your first automated test in under 2 minutes.

---

## 1. Install ZeniTest CLI

Install the CLI globally using your preferred package manager:

<Tabs>
  <TabItem label="npm">```bash npm install -g zenitest ```</TabItem>
  <TabItem label="pnpm">```bash pnpm add -g zenitest ```</TabItem>
  <TabItem label="yarn">```bash yarn global add zenitest ```</TabItem>
  <TabItem label="bun">```bash bun install -g zenitest ```</TabItem>
</Tabs>

---

## 2. Authenticate API Key

```bash
zenitest auth your_api_key
```

---

## 3. Install AI Agent Skill (Optional)

Enable coding assistants (Claude Code, Cursor, Codex, etc.) to generate and maintain tests automatically:

<Tabs>
  <TabItem label="npm">``` bash npx skills add zeni-org/zenitest ```</TabItem>
  <TabItem label="pnpm">
    ``` bash pnpm dlx skills add zeni-org/zenitest ```
  </TabItem>
  <TabItem label="yarn">
    ``` bash yarn dlx skills add zeni-org/zenitest ```
  </TabItem>
  <TabItem label="bun">``` bash bunx skills add zeni-org/zenitest ```</TabItem>
</Tabs>

---

## 4. Create Test Case

Save test scenarios in `.yaml` files inside `zenitests/web/`, `zenitests/ios/`, or `zenitests/android/`:

<Tabs>
  <TabItem label="Web">
    ```yaml
    id: tc_login
    title: SauceDemo Login Test
    localUrl: http://localhost:3000
    prodURL: https://www.saucedemo.com
    expectedResult: Inventory page loaded.

    steps:
      - navigate: /
      - act: Type 'standard_user' into 'Username'
      - act: Type 'secret_sauce' into 'Password'
      - act: Click 'Login'
      - validate: Verify 'Products' page title is displayed
    ```

  </TabItem>
  <TabItem label="Mobile">
    ```yaml
    id: tc_mobile_ecommerce
    title: Mobile Checkout Test
    expectedResult: Order placed successfully on iOS.

    steps:
      - act: Tap the Add button on ZeniPods Pro
      - validate: Cart badge displays 1
      - act: Tap the Cart icon
      - act: Tap Proceed to Checkout
      - validate: Verify Order Placed Successfully! text is displayed
    ```

  </TabItem>
</Tabs>

---

## 5. Run Tests

Execute web or mobile test suites from your terminal:

<Tabs>
  <TabItem label="Web">```bash zenitest run --platform web ```</TabItem>
  <TabItem label="iOS">
    ```bash zenitest run --platform ios --bundle ./build/Runner.ipa ```
  </TabItem>
  <TabItem label="Android">
    ```bash zenitest run --platform android --bundle ./build/app-debug.apk ```
  </TabItem>
</Tabs>

That's it! ZeniTest will execute your test actions and report real-time pass/fail status in your terminal. For detailed mobile testing options, see the [Mobile Testing Guide](/guides/mobile-testing/).
