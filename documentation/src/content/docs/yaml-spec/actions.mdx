---
title: Step Actions
description: The 3 core step actions used to write ZeniTest tests.
---

Every test is built using three straightforward actions:

---

## 1. `navigate` (Web only)

Opens a webpage or URL.

```yaml
- navigate: /
- navigate: /login
- navigate: /settings
- navigate: https://example.com/pricing
```

---

## 2. `act`

Tells ZeniTest what to do on the screen in plain language.

### Typing Text
```yaml
- act: Type 'john@example.com' into the Email input field
- act: Type '${secret.PASSWORD}' into the Password input field
```

### Clicking & Tapping
```yaml
- act: Click on the 'Sign In' button
- act: Tap the 'Add to Cart' button
- act: Tap the Shopping Cart icon
```

### Selecting, Checking & Scrolling
```yaml
- act: Select 'Price: Low to High' from dropdown
- act: Check the 'I agree to Terms' checkbox
- act: Scroll down to product reviews
```

---

## 3. `validate`

Checks that an element, text, or page state is displayed as expected.

```yaml
- validate: Verify 'Welcome back, John' is visible
- validate: Cart badge shows '1'
- validate: 'Order Placed Successfully!' message is displayed
- validate: Verify the 'Checkout' button is enabled
```

---

## Tips for Writing Steps

1. **Use visible text**: Write the exact words you see on the button, link, or input label (e.g. `Click 'Submit'`, `Type into 'First Name'`).
2. **Keep each step focused**: Do one action per `act` line (e.g. type text first, then click button on the next line).
3. **Validate key milestones**: Add a `validate` step after important transitions (like form submissions or page changes).
